# Crustdata

Crustdata provides company and person enrichment/search, social-post lookup,
and workspace-owned watcher resources through the catalog. Watchers are tracked
per workspace and expire after 24 hours through the vendor's delete status
operation; stateless lookups remain shared and read-only.

Vault source: `CRUSTDATA_API_KEY`.

Official documentation reviewed 2026-10-13: [Crustdata API docs](https://docs.crustdata.com).
