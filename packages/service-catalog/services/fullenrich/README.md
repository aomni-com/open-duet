# FullEnrich

FullEnrich provides contact enrichment, reverse-email lookup, and people/company
search through the proxy. Async enrichment and reverse-email polling use the
opaque ids returned by the caller's own start request; the proxy exposes no
job-list route and no vendor credential reaches an agent.

Vault source: `FULLENRICH_API_KEY`.

Official documentation reviewed 2026-10-13: [FullEnrich API docs](https://docs.fullenrich.com).
