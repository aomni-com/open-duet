# DataForSEO

DataForSEO uses vendor Basic authentication behind the proxy. The catalog
admits the SEO, SERP, AI-search, shopping, Amazon, and app-store routes used by
the registry. Task polling uses opaque ids returned by the caller's own start
request; there is no task-list route. Vendor response costs remain the billing
source where the route exposes them.

Vault source: `DATAFORSEO_BASE64_PASSWORD`.

Official documentation reviewed 2026-10-13: [DataForSEO API docs](https://docs.dataforseo.com).
