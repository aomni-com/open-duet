# Editorial Pass

`AGENTS.md` owns the folder layout, the two-pass rule, and the editorial note. This is the part that decides *what kind of edit this is* — and how to write down a voice before you overwrite it.

## Diagnose first

Answer these in `diagnosis.md` before touching a sentence. They decide whether the piece needs restructuring or polishing, and that decision cannot be made from inside the prose.

1. **What does it argue?** One sentence. If you cannot write it, that is the finding — the piece has no spine and no amount of line editing will give it one.
2. **Does the order earn itself?** Read only the headings and first sentences. If that skeleton does not track, the problem is structure.
3. **What is each paragraph's job?** A paragraph with two jobs is two paragraphs; a paragraph with none is a cut.
4. **What is promised but never delivered?** Openings routinely promise a payoff the draft never pays.
5. **What is asserted but never supported?** These become `[verify]`, never quiet deletions.

If 1 or 2 fails, stop and hand back the diagnosis. Polishing a piece whose argument does not hold makes it *feel* finished, which is worse than leaving it visibly rough.

## Check the draft against the trained voice

`voice/author-voice.md` is the voice contract — the profile onboarding wrote from the author's own samples. Read it before editing, and check the revision against it, not against taste. What to look for in the draft, quoting evidence when it teaches you something new:

- **Sentence rhythm** — is length varied on purpose? A short sentence doing work after a long one is a choice.
- **Deliberate fragments** — fragments that recur are a choice; a single one may be an error.
- **The author's own metaphors** — these are the first thing a rewrite flattens and the last thing an author forgives.
- **Recurring word choices** — a word used three times is vocabulary, not repetition.
- **Register** — where the piece sits between formal and conversational, and whether the profile licenses it.

A draft that shows a trait the profile does not carry is a finding: quote it and append it to `voice/author-voice.md`, so the profile stays the one owner of the voice rather than each edit rediscovering it. No profile yet means no licence to edit voice — offer the Voice Setup app first.

## Tic or signature

The hardest call in this job. Before "fixing" an oddity:

- Does it appear **more than once**? Once is likely an error; a pattern is likely a choice.
- Does it **do work** — pacing, emphasis, humour? Then it is a signature even if a style guide forbids it.
- Would fixing it make the sentence **more correct but less like this author**? Then leave it and note it.

When still unsure, leave it and put it in the note's "left alone" section. An author can accept a change you flagged; they cannot recover a voice you removed silently.

## Scope check

Before returning: what fraction of sentences did you touch? Past roughly a third, this stopped being an edit and became a rewrite — hand back the diagnosis and ask, rather than delivering a piece the author no longer recognises.
