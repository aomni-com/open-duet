# Writing Emails

Compose effective, context-appropriate emails for business communication.

## Before Drafting: Assess Context

**Evaluate what you know before asking questions.** If the user has provided sufficient context (recipient, purpose, key details), proceed to drafting. If critical information is missing, ask targeted questions.

### When to Ask Questions

Ask only when missing information would significantly affect the email:

| Email Type | Ask If Missing                                            |
| ---------- | --------------------------------------------------------- |
| Sales      | Recipient role, offering/value prop, any research on them |
| Follow-up  | Previous interaction, what changed, goal                  |

**Never assume facts.** If you need specific numbers, names, dates, or claims—ask. Do not invent metrics, company details, or outcomes.

## Core Principles

### Brevity

- **Outreach emails**: 25-75 words
- **Response emails**: 50-125 words
- **Reading level**: Write at 5th grade level for higher response rates
- **Paragraphs**: 1-2 sentences max; embrace white space

### Personalization

- Reference specific observations about the recipient
- Connect to their actual situation or challenges
- Avoid generic phrases that could apply to anyone

### Structure

1. **Opening**: Context or observation (never "I hope this finds you well")
2. **Body**: Single core message
3. **Close**: One clear ask or next step

## Subject Lines

- **Length**: 1-5 words
- **Case**: Title case
- **Tone**: Neutral, descriptive
- **Avoid**: Questions, exclamation marks, ALL CAPS, urgency markers, numbers

The preview text (first line of email) matters more than the subject. Make it count.

## Tone Framework

| Tone           | When to Use                                | Characteristics                                           |
| -------------- | ------------------------------------------ | --------------------------------------------------------- |
| Formal         | External executives, legal, official comms | Complete sentences, titles (Mr./Ms./Dr.), no contractions |
| Professional   | Most business communication                | Clear and direct but warm, contractions OK                |
| Conversational | Colleagues, warm relationships             | Friendly, relaxed, still respectful                       |
| Urgent         | Time-sensitive matters only                | Bold key points, explicit deadlines, short sentences      |

Use urgent tone sparingly—overuse dilutes impact.

## Pre-Send Checklist

Before presenting the draft:

- [ ] Subject line is specific and under 5 words
- [ ] First line works as preview text
- [ ] One clear purpose per email
- [ ] Appropriate length for email type
- [ ] Tone matches recipient and context
- [ ] No assumed facts or invented details
- [ ] Single, clear call-to-action
- [ ] No jargon or buzzwords
