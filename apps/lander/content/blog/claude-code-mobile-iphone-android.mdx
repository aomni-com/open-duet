## The Mobile Workflow for Claude Code

Duet's mobile experience is built around three lightweight moments that keep your Claude Code agents moving even when you're away from your desk.

### Check-In

Open the Duet app and you'll see a list of your active agents. Each card shows status at a glance — running, waiting for input, or completed. Tap any agent to view its current task, recent output, and how long it's been working. No need to remember what you kicked off last night; the app surfaces the context instantly.

### Quick-Edit

Found an issue or want to steer the agent in a new direction? Tap the prompt or instructions section and make your change directly in the app. The updated instructions are sent to the server immediately, so the agent picks up the new guidance on its next step. This is perfect for course-correcting mid-run without firing up a laptop.

### Ship

When the agent finishes or reaches a decision point, you'll get a notification. Review the output in the app, approve the final result, or trigger the next action, all without leaving the couch. For many workflows, the entire review-and-ship cycle happens on your phone.

These three interactions, check-in, quick-edit, ship, are the core of Duet's mobile Claude Code workflow. They don't replace deep desktop coding sessions, but they remove the friction of "I can't touch this until I'm back at my desk."

## Duet Desktop vs Mobile

Duet's mobile apps don't replace the desktop experience, they complement it. Knowing when to reach for your phone versus your laptop keeps you productive without forcing every task into the smaller screen.

### Use Mobile When You Need

- **Quick status checks:** See if an overnight agent finished or is still running without opening a laptop.
- **Light prompt tweaks:** Fix a typo, adjust a constraint, or add a missing detail while you're on the move.
- **Approvals and shipping:** Review output and give the green light from anywhere. Notifications and one-tap actions make this frictionless.
- **Between-meeting or couch moments:** Short, focused interactions that don't require deep context or heavy editing.

### Stick to Desktop When You Need

- **Long-form prompt engineering:** Writing or refactoring complex multi-step instructions is faster and more accurate on a full keyboard.
- **Deep code review:** Reading large diffs, comparing outputs, or debugging detailed results is easier with more screen real estate.
- **Multi-agent orchestration:** Managing several agents in parallel or building new workflows from scratch benefits from the richer desktop interface.
- **Heavy collaboration:** Sharing detailed context, commenting on specific lines, or pairing with teammates is smoother on a larger screen.

The pattern most Duet users settle into is simple: desktop for creation and deep work, mobile for momentum. You start a complex Claude Code run on your laptop, then use the iOS or Android app to keep it moving throughout the day. When the agent hits a decision point or finishes, the phone is enough to review and ship, no context switch required.

This split keeps you in flow without the old "everything waits until I'm back at my desk" bottleneck.
