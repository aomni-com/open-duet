## Claude Code Pro vs Max vs uso de API

Claude Code tiene tres modelos de precios que se ven similares en la superficie pero se comportan de forma muy distinta en la práctica. Elige el equivocado y o chocas con un muro a media tarde o pagas dos a tres veces lo que necesitabas.

### Planes de suscripción (Claude Pro y Claude Max)

Este es el punto de entrada más común. Pagas una tarifa mensual plana y obtienes una asignación de tokens que se reinicia en una ventana móvil de 5 horas, con un techo semanal por encima. Hay tres niveles:

- **Claude Pro: $20/mes.** Acceso a Sonnet 4.6 y Opus 4.7, aproximadamente 44,000 tokens por ventana de 5 horas, y cerca de 40 a 80 horas de uso de Sonnet por semana. Suficiente para sesiones de programación concentradas, no suficiente para usar Claude Code todo el día como tu IDE principal.
- **Claude Max 5x: $100/mes.** Alrededor de 88,000 tokens por ventana de 5 horas y 140 a 280 horas de Sonnet más 15 a 35 horas de Opus por semana. Hecho para desarrolladores que chocaban con los límites de Pro a diario.
- **Claude Max 20x: $200/mes.** Aproximadamente 220,000 tokens por ventana de 5 horas, 240 a 480 horas de Sonnet, y 24 a 40 horas de Opus por semana. Este es el nivel donde los límites de tasa dejan de interrumpir tu día.

![Claude Code plan token allowances compared](/blog/claude-code-pricing/plan-ladder.png)

Un detalle importante: tu límite de uso se comparte entre el chat de Claude.ai y Claude Code. Si quemas tokens chateando con Claude en el navegador, eso consume del mismo balde del que Claude Code extrae.

### Precios de API de Claude Code

En vez de una suscripción, puedes pagar por token a través de la API de Anthropic. Claude Code se autentica con una API key y te cobra según lo que realmente usas.

Tarifas actuales:

- Opus 4.7: $5 por millón de tokens de entrada, $25 por millón de tokens de salida
- Sonnet 4.6: $3 de entrada, $15 de salida por millón de tokens
- Haiku 4.5: $1 de entrada, $5 de salida por millón de tokens
- Prompt caching: las escrituras de caché de 5 minutos cuestan 1.25x la tarifa de entrada, las escrituras de caché de 1 hora cuestan 2x, las lecturas de caché cuestan 0.1x

Algo a vigilar: Opus 4.7 viene con un nuevo tokenizador que puede producir hasta un 35% más de tokens para el mismo texto de entrada en comparación con Opus 4.6. La tarifa por token no cambia, pero tu costo efectivo por prompt puede ser más alto simplemente porque el mismo código se tokeniza en más piezas.

La facturación por API es precisa pero impredecible. Un uso intensivo de Opus en un codebase grande puede llegar fácilmente a $30 a $60 por día. Ese es el impuesto de la flexibilidad.

### Planes de equipo y Enterprise de Claude Code

Para grupos, Anthropic ofrece planes Team que empiezan en $20/asiento/mes en Standard, pero Claude Code solo se incluye en asientos Premium a $100/asiento/mes (facturación anual) o $125/asiento/mes (facturación mensual), con un mínimo de 5 asientos. Puedes mezclar asientos Standard y Premium en el mismo equipo.

Enterprise desbloquea una ventana de contexto de 500K, preparación para HIPAA, SSO, retención de datos personalizada y precios personalizados a través de ventas de Anthropic. Es la opción correcta si compliance o procurement están en la sala.

### El nuevo detalle del "uso extra"

En 2026, Anthropic añadió un interruptor de "uso extra" en cada plan de consumidor pagado. Cuando llegas a tu límite incluido, en vez de detenerte en seco, puedes optar por continuar a tarifas estándar de API con un tope mensual de gasto que tú controlas.

Esto importa más de lo que suena. Convierte la decisión de Pro vs Max de "qué techo quiero" a "qué línea base quiero, y cuánto desborde estoy cómodo pagando".

![Extra usage toggle in Claude account settings](/blog/claude-code-pricing/extra-usage-toggle.png)

### La trampa en la que todos caen

Si tienes una variable de entorno `ANTHROPIC_API_KEY` configurada en tu máquina, Claude Code usará la API key en silencio en vez de tu suscripción Pro o Max.

Te seguirán cobrando a través de la API mientras tu plan Max de $200/mes queda ahí sin usarse.

Revisa tu perfil de shell antes de pagar por una suscripción. Este es el error de precios de Claude Code más común que vemos.

### Más sobre la tabla

**Columna de precio.** Max 5x y Max 20x no son "un Pro mejor". Son baldes más grandes. El techo sube, el acceso al modelo se mantiene igual.

**Ventana de 5 horas.** Este es el presupuesto móvil. Cada prompt cuesta tokens; los tokens se reinician 5 horas después de tu primera solicitud de una sesión. Si pasas esto por alto, vas a pensar que Claude Code "se rompió" a las 3 p. m.

**Límites semanales.** Añadidos en agosto de 2025 para frenar el uso en segundo plano 24/7. La mayoría de los usuarios nunca los alcanza. Los usuarios intensivos que corren Claude Code en varios repos toda la semana pueden hacerlo.

**Modelos.** Pro, Max y Team obtienen los mismos modelos de Claude. Lo que difiere es cuánto puedes usarlos.

**Opus vs Sonnet.** Opus es el modelo caro y más inteligente. En planes Max obtienes una asignación semanal separada para Opus encima de Sonnet. En Pro, el acceso a Opus es lo suficientemente limitado como para que la mayoría de los usuarios de Pro usen Sonnet por defecto.

### ¿Qué plan de Claude Code le conviene a qué comprador?

- **Aficionado, estudiante, usuario ocasional.** Claude Pro. No vas a sobrepasar los $20/mes.
- **Desarrollador en activo programando de 4 a 6 horas/día.** Pro con uso extra habilitado, o Max 5x si chocas con el muro cada semana.
- **Claude Code es tu IDE principal.** Max 20x. Deja de pelear con los límites.
- **Equipo de 5+ con una sola factura.** Asientos Team Premium, o una plataforma administrada con precios planos.
- **Agencia con cargas variables y a ráfagas.** API para las ráfagas, o Duet por predictibilidad.
- **Salud, finanzas, regulado.** Enterprise, sin atajos.

### Dónde la tabla de comparación miente un poco

Dos asteriscos que vale la pena conocer:

1. **"Tokens por ventana de 5 horas"** es la estimación de Anthropic basada en uso promedio. Los codebases grandes queman tokens 3 a 5x más rápido que el promedio porque cada archivo que cargas consume contexto. Un monorepo de 200K líneas en Pro chocará con los límites mucho antes de lo que sugiere "44K tokens".
2. **Los asientos de Team** requieren un mínimo de 5 asientos. Una startup de 3 personas no tiene una opción limpia con Anthropic. O compras 5 asientos y desperdicias 2, o apilas suscripciones Max individuales y pierdes la facturación centralizada.

**Perfil.** Ocho desarrolladores rotando entre una docena de codebases de clientes, muy a ráfagas (todos al frente durante semanas de sprint, tranquilidad entre medias). Necesita acceso compartido, no cálculos por asiento.

### El patrón

Mira los cuatro escenarios y una cosa resalta: los precios directos de Anthropic están optimizados para el **usuario intensivo individual** (Max 20x es genuinamente una ganga a 300M+ tokens).

Se vuelve incómodo para **equipos con uso disparejo** y **agencias con cargas a ráfagas**, porque las asignaciones por asiento no se comparten y los precios de Team asumen que todos lo usan por igual.

## Costos ocultos de Claude Code que vigilar (tokens, ventanas de contexto, llamadas MCP)

El precio de lista es solo la mitad de la historia. Lo que hace que los precios de Claude Code sean genuinamente difíciles de predecir son las mecánicas por debajo, las cosas que multiplican en silencio tu consumo de tokens sin aparecer en la página de comparación de planes. Aquí están los cuatro que más confunden a la gente.

### El impuesto de la ventana de contexto

Cada vez que Claude Code lee un archivo, ese archivo se queda en la ventana de contexto por el resto de la conversación. Pídele a Claude que "mire el módulo de auth" en un repo grande y podrías cargar 40,000 tokens antes de haber escrito un solo prompt real. Cada mensaje posterior reenvía ese contexto.

El efecto práctico: una sesión de 30 minutos en un codebase grande puede quemar 300K a 500K tokens aunque solo hayas enviado 10 mensajes. En Pro, eso es una porción significativa de tu asignación de 5 horas perdida antes del almuerzo. En la API, eso son dólares reales. Una sesión larga de Opus puede costar en silencio $15 a $25.

**Qué hacer.** Usa `/clear` entre tareas no relacionadas. Evita cargar directorios enteros cuando un solo archivo basta. Si estás en Pro y chocas con los límites rápido, el 80% del tiempo el culpable es el contexto, no la cantidad de prompts.

### Los tokens de salida cuestan 5x los tokens de entrada

Los precios de API tienen dos números por una razón. Los tokens de entrada (lo que envías) son baratos. Los tokens de salida (lo que Claude escribe de vuelta) son 5x más caros en todos los modelos. Una solicitud que cuesta $0.10 en entrada puede costar $0.50 en salida si Claude escribe un archivo largo.

Esto importa más para Claude Code específicamente, porque la generación de código es intensiva en salida. "Reescribe este componente de 400 líneas" es un prompt caro. "Revisa este componente de 400 líneas y sugiere 3 cambios" es 10x más barato.

**Qué hacer.** Prefiere ediciones puntuales en vez de reescrituras completas. Pide diffs, no archivos. Si estás en facturación por API, este único hábito puede reducir tu gasto mensual a la mitad.

### Servidores MCP y llamadas de herramientas

Los servidores del Model Context Protocol extienden Claude Code con herramientas externas: GitHub, bases de datos, navegadores, APIs personalizadas. Son poderosos, pero cada llamada de herramienta es un viaje de ida y vuelta. Claude lee la salida de la herramienta, lo que se suma al contexto, lo que se suma al costo.

Una sola llamada MCP de "revisa los últimos 20 PRs" puede cargar 8,000 tokens de metadatos de PRs al contexto, donde luego se quedan por el resto de tu sesión. Encadena tres o cuatro llamadas MCP en una conversación y habrás añadido 30K a 50K tokens de ruido de fondo a cada prompt posterior.

**Qué hacer.** Audita qué MCPs se cargan en cada sesión vs bajo demanda. Apaga los que no uses. Para MCPs caros (como indexadores de repo completos), prefiere las llamadas explícitas en vez de la carga automática.

### Prompt caching

Este corta para el otro lado. Es un _ahorro_ oculto. El prompt caching de Anthropic te deja reutilizar una porción del contexto sin pagar el precio completo de entrada. Las escrituras de caché cuestan 1.25x la tarifa de entrada, pero las lecturas de caché cuestan apenas el **10%** de la tarifa de entrada.

Para Claude Code, esto importa enormemente. Tu system prompt, los archivos comunes del proyecto y el historial de conversación de larga duración pueden cachearse todos. Cuando el caché funciona bien, los costos de entrada pueden bajar entre 80 y 90%.

El truco: el caché solo ayuda en la facturación por API. Los planes Pro y Max ya incluyen el caché en su tarifa plana, pero no ves el ahorro, simplemente obtienes un uso un poco más efectivo. Si estás en API, asegúrate de que el caché esté realmente habilitado. Muchas configuraciones de Claude Code no lo activan por defecto.

### La trampa de sobreescritura de suscripción

Vale la pena repetirlo de antes: si `ANTHROPIC_API_KEY` está configurada en tu shell, Claude Code usa la API key y te cobra a tarifas de API, ignorando por completo tu suscripción de $20 a $200. La gente descubre esto cuando ve una factura de API de $400 encima de su plan Max de $200.

**Qué hacer.** Corre `echo $ANTHROPIC_API_KEY` en tu terminal. Si imprime algo, o la desactivas antes de usar Claude Code, o aceptas que tu suscripción no está haciendo nada.

### La meta-lección

El costo real de Claude Code no es el plan que eliges. Es cómo trabajas. Un usuario disciplinado de Pro puede lograr más que un usuario descuidado de Max 20x, porque el usuario de Pro no está quemando 200K tokens por sesión en contexto rancio y reescrituras verbosas. Trata tu ventana de contexto como un presupuesto, no como un colchón.

### Qué significa "administrado" en realidad

En vez de que cada desarrollador instale Claude Code localmente con su propia API key o suscripción, Duet corre Claude dentro de un entorno de equipo compartido. Cada compañero obtiene acceso a través del mismo workspace, así que los prompts, el contexto y las conversaciones ocurren en un solo lugar que todo el equipo puede ver.

La implicación de precios es lo que la mayoría busca: **planes mensuales con créditos incluidos compartidos y una reserva pagada para uso adicional.**

### Cuándo Duet le gana a comprar Anthropic directo

**Un equipo de 3 a 10 con uso disparejo.** El plan Team de Anthropic exige 5 asientos Premium a $100 cada uno, incluso si dos desarrolladores usan Claude Code dos veces por semana. Los créditos mensuales de Duet se comparten en el workspace en lugar de dividirse por asiento.

**Quieres una base predecible con uso adicional visible.** El precio del plan fija la base mensual y la reserva pagada hace explícito un mes intenso mediante recargas manuales o automáticas y una factura por cada cargo.

**Quieres contexto compartido.** En Claude Code directo, la sesión de cada desarrollador está aislada. En Duet, tu equipo trabaja en sesiones duraderas compartidas, así que la investigación, las decisiones y los resultados anteriores permanecen disponibles en vez de quedar atrapados en terminales individuales.

**Eres una agencia rotando entre codebases de clientes.** Duet te deja levantar workspaces separados por cliente sin suscripciones separadas de Anthropic, y el uso se comparte en todo tu equipo en vez de estar fijado a asientos individuales.

**Quieres Claude Code _más_ el resto de tu stack.** Duet combina el acceso a Claude con integraciones para GitHub, Google Sheets, Slack y cientos de otras herramientas a través de fronteras de integración administradas. No solo estás pagando por Claude. Estás pagando por la infraestructura que hace a Claude útil para los equipos.

- **Enterprise con restricciones de SSO, HIPAA o procurement.** Anthropic Enterprise es la respuesta correcta cuando compliance está en la sala.
- **Automatización pura de API.** Si estás cableando Claude dentro de un producto (no para desarrolladores), la API es la primitiva correcta.

## Epílogo

Los precios de Claude Code parecen complicados porque lo son, pero una vez que quitas los niveles y las tablas de tokens, la decisión se reduce a tres preguntas:

**¿Cuánto lo usas en realidad?** Bajo 50M tokens al mes, Pro o API está bien. Por encima de 200M, Max 20x gana por mucho. El medio es donde las elecciones importan.

**¿Eres una persona o un equipo?** Los planes directos de Anthropic recompensan a los individuos y penalizan a los equipos disparejos. Una plataforma administrada equilibra eso.

**¿Cuánto te importa la predictibilidad?** Los precios de API son la opción más barata en un buen mes y la más cara en uno malo. Las suscripciones aplanan esa curva. Las plataformas administradas la aplanan aún más.

El peor resultado no es pagar de más $50/mes. Es elegir un plan, chocar con un muro a media tarde y perder tres horas de estado de flow por un límite de tasa. Lo que sea que elijas, elígelo con suficiente margen para no volver a pensar en ello.

## Preguntas frecuentes

### ¿Claude Code es gratis?

No. No hay un nivel gratis de Claude Code. Necesitas al menos una suscripción Pro ($20/mes), un plan Max, un asiento Team Premium o créditos de API para usarlo. Anthropic experimentó brevemente con incluir Claude Code en los niveles gratis pero dio marcha atrás.

### ¿Cuánto cuesta Claude Code por mes?

Claude Code cuesta $20/mes en Claude Pro, $100/mes en Claude Max 5x, o $200/mes en Claude Max 20x. Los planes Team son $100/asiento/mes para asientos Premium (mínimo 5 asientos). También puedes pagar por token a través de la API de Anthropic, que va de $1 a $25 por millón de tokens según el modelo.

### ¿Cuál es la diferencia entre Claude Pro y Claude Code?

Claude Pro es la suscripción de $20/mes que incluye Claude.ai (la interfaz de chat) _y_ Claude Code (el agente de programación en tu terminal). Comparten los mismos límites de uso. "Precios de Claude Code" es en realidad "precios de la suscripción de Claude, aplicados a Claude Code".

### Claude Pro vs Max: ¿cuál da más de todo?

A grandes rasgos, sí. Max 5x te da aproximadamente 5x la asignación de tokens de Pro por ventana de 5 horas, y límites semanales proporcionalmente más grandes. Max 20x te da aproximadamente 20x Pro. El acceso al modelo es idéntico en todos los niveles. Estás pagando por un balde más grande, no por un Claude mejor.

### ¿Puedes usar una suscripción Pro para Claude Code en la API?

No, estos son sistemas de facturación separados. Tu suscripción Pro o Max cubre el uso a través de la autenticación integrada de Claude Code. El acceso a la API se factura por separado por token. Y si tienes `ANTHROPIC_API_KEY` configurada en tu entorno, Claude Code usará la API y te cobrará por separado de tu suscripción.

### ¿Qué pasa cuando llego a mi límite de uso de Claude Code?

En Pro y Max, Claude Code deja de responder hasta que se reinicia tu ventana de 5 horas. Si habilitaste el "uso extra", el desborde continúa a tarifas estándar de API hasta un tope mensual que tú fijas. En la API, no hay tope. Sigues pagando por token.

### ¿Vale la pena Claude Max 20x para la mayoría de los desarrolladores?

Solo si Claude Code es tu entorno de desarrollo principal y programas 6+ horas al día. Para la mayoría de los desarrolladores en activo, Max 5x a $100/mes es el punto justo. Para usuarios ocasionales, Pro es suficiente.

### ¿Cómo funcionan los planes de equipo de Claude Code?

Los planes Team de Anthropic empiezan en $20/asiento/mes (anual) para acceso Standard, pero Claude Code específicamente requiere un asiento Premium a $100/asiento/mes (anual) o $125/asiento/mes (mensual), con un mínimo de 5 asientos. Puedes mezclar asientos Standard y Premium en un equipo. El uso no se comparte entre asientos. Cada desarrollador tiene sus propios límites.

### ¿Hay una alternativa más barata a Claude Max 20x para usuarios intensivos?

La respuesta honesta es no, no de Anthropic directamente. Max 20x a $200/mes ya tiene un precio agresivo frente al uso equivalente de API. Si eres un equipo, las plataformas administradas como Duet pueden ser más baratas porque el uso se comparte entre desarrolladores, pero para un solo usuario intensivo, Max 20x es el mejor trato del mercado.

### ¿Los precios de Claude Code incluyen Opus 4.7?

Sí. A abril de 2026, Opus 4.7 está disponible en todos los niveles pagados: Pro, Max 5x, Max 20x y Team Premium. Anthropic ha movido Opus 4.6 a estado heredado. El nivel gratis sigue limitado a Sonnet 4.6. Revisa la [página de precios de Anthropic](https://claude.com/pricing) para la lista de modelos más reciente.

### ¿Puedes cambiar entre planes de Claude Code?

Sí. Puedes subir o bajar de nivel mensualmente. Las bajadas de nivel surten efecto en el siguiente ciclo de facturación. No hay contratos a largo plazo para Pro o Max. Puedes pasar de Max 20x de vuelta a Pro en cualquier momento.
