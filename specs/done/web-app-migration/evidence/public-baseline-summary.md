# Frozen public baseline

The post-extraction Duet tree was labeled
`a31458d03d6328413db1f33dd2cb6cc166eb562e` when the baseline was generated. That
identifier is provenance recorded inside the capture, not a surviving Git object or a
`chat-app` history cursor. Duet commit `fb1570d` committed the immutable bundle after
the repository history was rewritten. The capture described the incumbent route and
redirect universe, sitemap membership, normalized HTML signals, deployable assets,
public-form responses, locale cookie, and visual coverage. Checksums made the bundle
tamper-evident while ownership moved.

That capture proved the atomic transfer, including the bilingual editorial and
marketing corpus, before the two apps became independent. The executable
comparison and its raw build manifest were intentionally retired afterward:
they duplicated obsolete output and encoded the pre-split host and cookie
model. Enduring parity is now enforced by the lander route/content/build
inventories, visual registry, and deployed staging crawl. The user explicitly
retired comparison against the incumbent's moving sitemap as a completion gate.
