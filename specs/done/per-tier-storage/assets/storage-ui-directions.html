Three decisions this mock forces

Q-A · What counts as "used"? The meter must count /home/synthetic-user/drive bytes only — the existing telemetry reports whole-filesystem diskUsedMb, which would show ~7.2 GB used on an empty workspace. Gateway measures the drive dir instead.
Q-B · Per-workspace or pooled? As mocked, the quota is per workspace: a Starter with 3 workspaces holds 3 × 20 GB. The alternative — one pooled 20 GB across all workspaces — is stricter and needs cross-VM accounting.
Q-C · Nudge threshold 90%? Credits warn at 90% used (LOW_CREDIT_WARNING_RATIO). Same ratio for storage as mocked.
