# Private migration retirement

The [receipt](receipt.json) records deletion of temporary original/recovery copies, collected-job programs and the obsolete gateway bootstrap on both fleets. Each deletion required complete current and previous ordinary releases, real earlier certification of that exact previous version, all recorded job identities, matched host settlement and no live reference to the retiring paths.

The cleanup preserved generic bootstrap wiring, current and rollback inventories, health, OS boot and the gateway process. It performed no signals or service restarts. Different historical bootstrap hashes were pinned per VM. Temporary transport directories were removed after matching terminal receipts were collected.

The source transition helper, host/job controller, temporary lifecycle fence/replay code and raw disposable producers are now retired. Both deployed lifecycle environment flags were removed explicitly; the ordinary runtime-update pause control remains. This records migration closure before final repository and external publication checks; the [release evidence](../../release-integration/README.md) records their outcome.
