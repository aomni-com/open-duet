# Fleet controller proof

These receipts record the one-time controller's inventory, transfer and settlement
contracts. The controller consumed the helper's bounded platform-job lifecycle;
it did not introduce another service supervisor. Its source belongs to the
recorded Git revision, rather than the ongoing VM delivery system.

Terminal adoption output alone did not authorize transfer deletion: cleanup
required matching platform settlement. Attachment discrepancies, busy work,
uncertain launches and lost cleanup responses remained explicit outcomes. A
complete in-place transition preserved OS boot identity.

[The receipt](receipt.json) binds the narrow counterexamples and credential-free
fleet plans. Its substituted transport edges establish controller behavior,
not actual provider adoption. [Canonical census proof](canonical-census-receipt.json)
covers the SDK reader across both row generations; the temporary former-column
input has no remaining operational consumer after fleet retirement.

Actual [staging outcomes](../staging/README.md) and the parent's systemd evidence
retain their separate proof boundaries. Ordinary runtime installation, repair,
activation and rollback stay with the gateway release manager.
